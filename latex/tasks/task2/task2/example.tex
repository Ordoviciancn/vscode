\section{引言}
本文以欧洲运筹学杂志 (EJOR)2025年刊发的论文\textbf{"Lagrangian relaxation and branch-and-price algorithm for resource assignment problem in divisional seru systems"} (拉格朗日松弛与分支定价算法在分部式单元生产系统资源分配问题中的应用)为核心研究对象, 围绕该论文聚焦的"\textbf{分部式单元生产系统资源分配}"核心问题展开深度探究. 研究过程中, 一方面系统梳理论文提出的问题建模逻辑与算法设计框架, 完整还原其从\textbf{问题解构}、\textbf{模型构建} (混合整数非线性规划与线性规划转化)到两阶段求解 (\textbf{拉格朗日松弛}筛选作业-单元分配方案、\textbf{分支定价算法}精确求解剩余子问题)的全流程研究思路; 另一方面, 结合该领域优化算法的应用特性与实际生产场景需求, 从求解效率提升、边界计算精度优化、加速策略适配性等维度, 探讨对原方法思路的改进方向, 旨在为分部式单元生产系统资源分配问题的高效解决提供更具实践适配性的优化路径. 
\section{问题背景分析}

在工业5.0推动制造模式向柔性化、人性化转型的趋势下, 分部式单元生产系统(SPS)作为传统装配线向全柔性单元系统过渡的关键形态, 其资源分配优化成为制造业的重要课题, SPS是一种起源于日本的电子装配企业的生产模式, 内部包含多个生产单元, 每个单元内部有一名或多名工人, 每个单元的工人可以灵活重组, 根据不同的生产任务和产品需求, 可以调整单元内的工人配置, 提高生产效率.具体背景可从三方面展开：

\subsection{制造模式转型的现实需求}

工业5.0强调''人-效率-可持续性''协同\cite{Destouet2023}, 传统大规模生产、精益生产等模式, 面对短产品生命周期、多品种小批量订单时, 因布局固化、工人技能单一难以快速响应\cite{Zhang2022a, Zhang2024b}. 而分部式单元系统以''部分交叉技能工人+可重构设备''为核心，既能减少工序浪费, 又能降低培训成本, 是平衡柔性与成本的关键选择\cite{Yin2018}. 但该系统高效运行依赖''作业-单元-工人-工序''精准匹配, 资源分配不当会导致成本激增, 因此优化需求迫切\cite{Chen2025}. 

\subsection{系统自身的复杂性约束}

一方面, 资源分配需同步解决作业-单元、工人-单元、工序-工人三大决策, 三者相互绑定——作业分配决定单元工序类型, 工人分配决定技能供给, 任一环节偏差都会影响整体成本\cite{Chen2025}; 另一方面, 成本目标需兼顾培训成本 (工人学新技能的费用)与加工成本 (工人技能水平系数$\beta_{ws}$直接影响效率), 两类成本存在权衡, 增加了优化难度\cite{Chen2025}. 

\subsection{现有研究的明显短板}

现有研究多聚焦旋转单元、台体单元等全柔性场景, 假设工人具备全交叉技能\cite{Yu2017, Wang2023}, 但实际中多数企业依赖仅含部分交叉技能工人的分部式单元, 研究贴合度不足\cite{Li2023b}; 求解方法上, 启发式算法\cite{Liu2013, Ying2017}难保证最优性, 精确算法\cite{Zhang2022b}效率低; 部分研究还简化作业为"单一工序", 无法反映实际多工序与技能的关联\cite{Wang2024}。

综上, 在模式转型、系统复杂、研究不足的背景下, EJOR 2025年Chen等\cite{Chen2025}的论文《Lagrangian relaxation and branch-and-price algorithm for resource assignment problem in divisional seru systems》聚焦此问题, 提出拉格朗日松弛-分支定价两阶段算法, 为高效求解提供新路径. 

\section{模型假设与符号说明}
在部门SPS中, 有$J$个工作需要分配给$I$个部门小组, 并有$W$名工人负责处理这些工作. 每个小组配备$K$台机器, 每台机器都设计用于处理需要特定技能的操作。每个工作都遵循预定义的处理路线，每个操作都需要工人使用配备了特定技能的相应机器来执行。每个工作和工人都必须分配到一个小组，以便完成所有工作的操作。为了确保各个小组之间工作量的均衡分配，需要均匀分配每个小组内的工作数量。此外，工作的每个操作都有固定的处理时间，并且只能由其指定小组中的一名工人执行。每个工人都必须至少掌握一种技能才能承担分配的操作，而技能掌握会产生培训成本。工人表现出异质性，并且对不同技能具有不同的偏好，这导致基于技能熟练度的每个操作的实际处理时间不同。针对工人技能习得的培训是根据他们分配的操作量身定制的，而小组之间的工人转移不予考虑。总体目标是设计出使生产成本（包括培训和处理）最小化的分配方案，并解决操作-工人分配（确定是否培训某种技能）以及工人-小组分配和工作-小组分配的确定问题。
